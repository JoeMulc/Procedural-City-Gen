# Procedural City Generation

This project uses a combination of extended Lindenmayer-Systems, pathfinding, shape grammars and subdivision algorithms to create the road networks, plots and buildings of a city. The generated city can be highly customised through the use of parameters. Static mesh instancing and LOD's ensure the genreated city is performant.
